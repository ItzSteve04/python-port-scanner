# Responsible Use

This TCP port scanner was created as a portfolio project to demonstrate Python programming, networking, and ethical security testing.

Only scan devices and systems that you own or have explicit permission to test. Do not scan third-party systems without authorization.

For authorized testing, stay within the agreed targets, ports, and scan rates. Scanning can trigger security alerts or affect sensitive services.

The `--authorized` flag acknowledges this requirement. It does not grant permission to scan any system.
